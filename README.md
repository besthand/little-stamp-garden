# 小小集點園

**小小集點園**是一個讓家長和孩子一起玩的親子集點遊戲，幫助孩子看見自己的進步、累積成就感，並在過程中練習訂定目標、耐心等待與做選擇。透過可愛的圖片印章和一起約定的小獎勵，把收好玩具、主動幫忙、勇敢嘗試等日常努力，變成看得見的小星星，讓孩子感受到：「我的努力，有被看見！」

孩子可以選擇自己的角色與佈景，挑選喜歡的圖片印章，再請家長幫忙解鎖蓋章。每個孩子都有獨立的點數與成長紀錄，也能留下得章原因，收藏那些被看見的小進步。

## 三種獎勵玩法

和孩子一起約定目標，再依孩子的步調選擇適合的玩法：

- **扣點兌換**：使用目前擁有的點數換取獎勵，兌換時扣除點數，可重複兌換。
- **集滿卡片**：每累積指定點數就能領獎一次，不扣除目前餘額；已用於領獎的累積點數不重複計算。
- **成長里程碑**：累積達標後解鎖特別獎勵，不扣除目前餘額，每位孩子限領一次。

獎勵可以是一場野餐、一本睡前故事，或一段由孩子決定的家庭遊戲時光。使用時，多說一句「我看到你今天主動把玩具收好了」，也保留不附帶點數的擁抱與肯定，陪孩子慢慢認識自己的努力與成長。

## 技術與功能

以原生 ES modules 製作的靜態親子集點網站，無後端、無執行期套件。

- 多孩子手冊、四種佈景、四種動物頭像、六種 PNG 圖片印章
- 獨立點數、原因選填、追加式歷程；兌獎分為扣點、重複累積卡、一次性里程碑
- 家長密碼使用畫面上的數字鍵盤，支援刪除一位、清空、確認，以及電腦實體數字鍵；輸入以圓點遮蔽，不會自動叫出手機鍵盤。首次家長操作設定 4–8 位數字密碼；最長 32 位連續輸入只要含完整密碼即可驗證
- PIN 使用隨機 salt + PBKDF2-SHA256 150,000 次；5 次錯誤後暫停 60 秒，逐次增加，最高 15 分鐘
- 5 分鐘家長工作階段，頁面隱藏立即上鎖；每次送出再檢查權限
- IndexedDB 保存資料與不可匯出的 HMAC 金鑰；載入驗證簽章，避免直接更動明文紀錄
- 備份為 PBKDF2-SHA256 310,000 次 + AES-256-GCM、隨機 salt 與 nonce、格式 AAD
- 匯入同時驗證備份密碼、備份中的家長 PIN、資料結構，再原子取代，不會自動合併
- Web Locks 防止多個分頁同時寫入相同家庭

## 使用

部署 `dist/` 到 HTTPS 靜態主機（Web Crypto / IndexedDB 需要現代瀏覽器）。首次載入體驗家庭。首頁上方直接切換孩子，中央為集點卡與主要蓋章按鈕。點「幫我蓋章」或空白格後，請家長解鎖，再於同一個視窗選擇六種圖片印章與點數，首頁不重複顯示選章區。

集點卡每張 20 格，使用紙卡背景、疊放紙邊和右側直向浮動的實際印章縮圖，讓孩子辨識自己的收藏。縮圖保留完成／成長圖樣，不加文字標籤。空格數字以大型、置中的淡色浮水印呈現，跨卡連續顯示（1～20、21～40……）；蓋章後直接顯示印章，不再疊加數字。手機每行至少 5 格，使用直向縮圖列的上下圖示按鈕切換卡片。孩子的主要按鈕至少 56～64px 高，文字與圖片一同放大。超過 20 點後，可點選收藏冊中的實際小卡縮圖，或使用大型上下箭頭圖示按鈕回看所有尚未使用的星星，點已蓋的印章可查看得章原因與時間。一次加多點會逐點呈現同次印章。扣點兌換或消點會先使用最早獲得的星星，再依剩餘點數整理卡片；原始得章與扣點紀錄仍保留在「我的成長足跡」。佈景名稱後方的調色盤圖示可切換佈景。集滿卡片與成長里程碑不扣餘額，因此不會移除卡片上的印章。

「家長小幫手」位於頁面底部，集中管理設定、消點與備份。首次使用在其中按「開始我的家庭」，即可設定家長密碼、清除體驗並建立孩子。集點卡下方固定顯示「扣點兌換、集滿卡片、成長里程碑」三個玩法入口與「全部小獎勵」。各玩法可篩選獎勵清單。家長小幫手只保留單一「管理獎勵」入口；解鎖後可在同一個清單新增獎勵、編輯名稱／兌獎規則／點數，並在編輯畫面移除獎勵。新增或移除完成後會回到管理清單。孩子的獎勵頁只保留查看與兌換，沒有新增或編輯入口。成長足跡仍在集點卡下方，沒有側邊導覽列或上方系統選單。

資料跟隨瀏覽器與來源網址；不會跨裝置同步。清除網站資料或更換網址前請匯出 `.garden` 加密備份。備份密碼與家長密碼均無法找回。

## 本機開發

不需要安裝執行期套件。使用 Node.js 24 執行檢查，或以 Python 3 啟動本機靜態網站：

```bash
python3 -m http.server 8000 --directory dist
```

開啟 <http://localhost:8000>。本機 localhost 可使用 Web Crypto；正式部署請使用 HTTPS。

```bash
npm test
npm run check
```

需要重新產生 PNG 圖片時：

```bash
python3 -m pip install -r requirements-dev.txt
python3 create-assets.py
python3 create-collection-assets.py
```

## 專案檔案

- `dist/`：瀏覽器原始碼、樣式和 PNG 圖片；ES modules 可直接部署，沒有另外隱藏的建置來源。
- `dist/ui-state.js`：彈窗、原始操作焦點、頁面與捲動容器的位置。
- `dist/pin-keypad.js`：數字鍵盤的暫存輸入、長度限制、刪除與清空；不保存或記錄輸入的密碼。
- `dist/child-play.css`：孩子操作區的卡片收藏冊、浮水印數字、觸控尺寸與字體。
- `create-assets.py`、`create-collection-assets.py`、`requirements-dev.txt`：完整圖片產生程式與開發相依套件。
- `tests/`：點數、兌獎、加密備份、卡片與 UI 狀態測試。
- `docs/`：已核准的設計、實作計畫及操作檢查紀錄。
- `.openai/hosting.json`：既有 Sites 靜態部署設定，不含家長密碼或家庭資料。

## 操作位置

點印章、換卡、選印章、換佈景等原地操作會保留目前頁面位置。關閉視窗時，焦點回到原本的按鈕，不再跳到頁尾的家長入口；連續家長驗證與操作視窗保留最初的位置。切換到獎勵或成長紀錄再返回，也會記住原本的頁面位置。彈窗先聚焦視窗本身，不會自動叫出手機鍵盤。家長解鎖、首次設定、更改密碼與匯入備份中的家長 PIN 均使用畫面上的數字鍵盤；有兩個欄位時點選要輸入的欄位，再按數字鍵。必須按確認才驗證，不會在輸入中途自動通過。備份加密密碼仍保留一般文字輸入。

## 驗證

`npm run check` 檢查 ES module 語法；`node tests/core.test.mjs` 驗證點數、三種兌獎規則、PIN、備份往返、密碼錯誤、竄改偵測及 HMAC。

此環境沒有 Sites 指定的 cua_repl 瀏覽器工具，因此沒有宣稱完成真實瀏覽器、IndexedDB 持久化或視覺回歸測試。

## 保護範圍

此為親子互信工具。虛位密碼不能保證抵抗多次觀察；PIN 位數有限，仍可能受到離線猜測。HMAC 能偵測直接修改紀錄，但同裝置執行的程式可使用該金鑰；無伺服器的瀏覽器系統無法抵抗完全控制裝置/程式的人，也無法阻止舊有效備份回溯或刪除儲存資料後重建家庭。備份採認證加密，可偵測檔案修改，無法偵測以相同密碼合法重新產生的檔案。

所有插畫與印章皆為本專案生成的 PNG 點陣圖片，生成腳本為 `create-assets.py` 與 `create-collection-assets.py`。Google Fonts 用於字型，無法連線時使用系統中文字型。家長密碼、家庭紀錄不傳送伺服器。
